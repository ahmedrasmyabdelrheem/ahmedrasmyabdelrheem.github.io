## 💼 Featured Projects

### 1. Customer Behavioral Segmentation & RFM Analysis
* **Tools:** SQL Server (T-SQL), Power BI, DAX
* **Overview:** Consolidated 12 months of transactional sales data using T-SQL window functions (`NTILE`) to calculate Recency, Frequency, and Monetary scores. Engineered multi-tier segmentation logic to classify 287 customer accounts into behavioral cohorts (identifying ~26% dormant and ~22% champions) and delivered an interactive Power BI dashboard with granular cohort transition tracking.
* **Key Focus:** Window Functions, Analytical Views, Customer Cohort Analysis, Interactive Dashboards.

### 2. Manufacturing Quality Control & Production Analytics
* **Tools:** Power BI, Power Query, DAX, Power BI Service, Google Sheets
* **Overview:** Architected an end-to-end operational data pipeline deploying 3 role-based Google Forms across 4 manufacturing lines. Leveraged Power Query to append and clean QC records, authored DAX measures to evaluate 25K+ garment inspections (tracking a 44.61% scrap rate and 5 line stoppages), and deployed the dashboard to Power BI Service with an automated 8-hour scheduled refresh.
* **Key Focus:** End-to-End Pipeline, ETL & Append, Shop-Floor KPIs, Root-Cause Analysis, Cloud Refresh.

### 3. Sales & Revenue Performance Executive Dashboard
* **Tools:** Microsoft Excel, Power Pivot, Power Query, DAX
* **Overview:** Designed a relational Star Schema in Power Pivot linking a central Fact table (`fOrders`) to Customer, Product, and Calendar dimensions. Developed advanced iterator DAX measures (`SUMX`, `AVERAGEX`, `DATEDIFF`) to evaluate $3.5M+ in revenue across 1,000 orders, isolating category trends, peak hours, and seasonal demand spikes.
* **Key Focus:** Dimensional Modeling, Star Schema, Advanced Iterator Measures, Executive Reporting.
